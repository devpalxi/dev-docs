## Adding a new guide

1. Pick the right folder, or create a new one (for example `git/`, `setup/`, `ai-agents/`).
2. Create a new `.md` file with a short, lowercase name using hyphens, like `branch-naming.md`.
3. Put `[← Back to all guides](../README.md)` at the top.
4. Add a link to it in the **Guides** section above.
5. Keep it simple: short steps, plain words, and links to official docs.
